# 리눅스 상태 점검 미션 제출 자료

필수 과제 수행 기록과 직접 제공한 실습 캡처를 모은 폴더입니다. 보너스 과제는 제외했습니다.

- [수행 내역서](수행_내역서.md): 환경·명령·검증 결과·평가 요소 설명과 실습 캡처 23장, 전체 스크립트 소스.
- [monitor.sh](monitor.sh): 실습 환경에서 검증한 제출용 Bash 소스.
- [전체 자료 ZIP](submission-with-captures.zip): 내역서·소스·캡처를 함께 내려받을 때 사용합니다.

수행 내역서를 다른 폴더로 옮길 때는 `captures/`도 함께 옮겨야 이미지가 표시됩니다.

앱 시작 캡처에는 Boot 5단계 `[OK]`가 확인됩니다. `Agent READY` 문구가 보이는 캡처는 추가 확인 항목으로 남겨 두었습니다.
